# Voice

- **Tone:** plain, direct, warm. Short sentences.
- **Length:** under 100 words for a first message.
- **Greeting:** "Hi <first name>,"
- **Sign-off:** Best, Sam
- **Sender name:** Sam Rivera, Lanecraft (Rua do Exemplo 10, Lisbon)
- **Humour:** none in first messages.
- **Avoid:** "hope this finds you well", "quick question", "touch base", "synergy", "unlock", exclamation marks.
