# Name and logos

The code in this repository is licensed under the Apache License 2.0. The license covers the code. It doesn't
cover the **floorboss** name, the floorboss pit boss mark and icons, or the **Panza Labs** name and windmill
mark.

## You're welcome to

- Use floorboss, unchanged or modified, at work or anywhere else.
- Say that your project is "based on floorboss" or "a fork of floorboss", with a link back to this repository.
- Use the name to refer to the original project, accurately, in articles, talks and reviews.

## Please don't

- Distribute a modified version under the floorboss name, or with the floorboss or Panza Labs logos. Pick a new
  name and new artwork for your fork.
- Name a product, service or company in a way that suggests it's floorboss or comes from Panza Labs.
- Suggest that Panza Labs makes, endorses or supports your version.

If you're unsure whether something is fine, open an issue and ask.
