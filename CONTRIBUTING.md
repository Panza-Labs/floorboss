# Contributing

Thanks for helping. A few things to know first.

## License of contributions

floorboss is licensed under the Apache License 2.0. By opening a pull request, you agree that your contribution
is licensed under the same license (Apache 2.0, section 5), and that you have the right to contribute it.

## Before you open a pull request

- Run the tests: `npm run unit`, then `npm run sims`. Don't run bare `node --test` on the whole repository; it
  runs the simulation runners and writes into the repository.
- Keep examples invented. No real people, real email addresses (use `example.com` or `.test`), real companies
  as customers, or real event names in tests, fixtures or docs.
- Say only what the code does and what the tests cover.

## Reporting a security problem

Please don't open a public issue. See SECURITY.md.
